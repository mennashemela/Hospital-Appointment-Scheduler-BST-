# Hospital-Appointment-Scheduler-BST-
Hospital Appointment Scheduler (BST)
A priority-based hospital appointment management system built with a Binary Search Tree, where appointments are ordered by urgency/priority level.

What was done
Designed an appointment class (name, priority level, department) and a BST keyed on priority level
Implemented recursive BST operations: insert, in-order traversal (display all), search by priority, delete-all-matching (cancel), and range queries (display more/less urgent than a given priority)
Loaded initial appointments from a file, then supported live interaction through a menu
Tools

C++ · Binary Search Tree · Recursion · File I/O

Deliverables
C++ source code (BST.h, main.cpp)
